# ResolveHub - Smart Complaint Management System

## About the Project
ResolveHub is a web-based application that allows users to submit complaints and track their status.

## Features
- Submit complaints through a form
- Store complaints permanently using SQLite
- View complaints on a dashboard
- Update complaint status
- View total, pending, in-progress, and resolved complaint counts

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite
- Git and GitHub

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/souravtolawani/Smart-Complaint-Management.git
   ```

2. Open the project folder:
   ```bash
   cd Smart-Complaint-Management
   ```

3. Create a virtual environment:
   ```bash
   python -m venv venv
   ```

4. Activate it on Windows PowerShell:
   ```powershell
   .\venv\Scripts\Activate.ps1
   ```

5. Install Flask:
   ```bash
   pip install flask
   ```

6. Start the application:
   ```bash
   python app.py
   ```

7. Open this URL in your browser:
   http://127.0.0.1:5000

## Database
The application uses SQLite to store complaint details and status.

## Project Purpose
This project demonstrates web application development, database integration, and Git-based version control.
